## Getting Started

Want to explore the source code or run the portfolio locally? Follow these steps.

### Prerequisites

You'll need:
- A modern web browser.
- Git installed on your system.
- A code editor such as Visual Studio Code.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Meet-Parsana1/Personal-Portfolio-Website
```

**2. Navigate to the project directory**

```bash
cd Personal-Portfolio-Website
```

**3. Open the project**

If it's a static HTML, CSS, and JavaScript website, open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

If the project uses a framework or build tool, follow the installation and development commands specified in its configuration files.
